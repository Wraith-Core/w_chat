# w_chat

## 1.2.0 — 2026-11-08

- شكل الشات صار على تصميم اللوحة الموحّد (نفس ألوان وخطوط لوحات القطار والصناعة): كل رسالة ورقة حبر ممزقة الأطراف، وسطر الكتابة بطاقة فيها حقل التصميم وزر «إرسال»، وقائمة الأوامر صفوف التصميم: الصف الذي عليه المؤشر بشريط الورق الأبيض، والأحمر علامة فقط (شريط على رسائل الإدارة والأخطاء، وعلى بطاقة الكتابة المفتوحة).
- الخطوط: EB Garamond للإنجليزي و Lalezar لكل العربي، والأرقام لاتينية. أُزيلت أيقونات Font Awesome وثيم المتجر من w_lib ونسخ الخطوط القديمة؛ الواجهة صارت أخف (حوالي 0.4 ميغا بدل 1.2).
- رتب VIP وألوان الأسماء المشتراة من المتجر باقية بألوانها، بدون التوهج الذهبي.
- الشات باقٍ في أعلى يسار الشاشة باللغتين (مكان شات اللعبة، وأعلى اليمين لأموال w_hud)، والكتابة داخله تبدأ من جهة اللغة.
- كل الكلمات من ملفات اللغة: عنوان قائمة الأوامر وتلميحها وزر الإرسال واسم القناة أثناء الكتابة (مثل «الشريف» بدل «الشرطة»).
- الماوس والأسهم يحركان مؤشرًا واحدًا في قائمة الأوامر، فـ Tab / Enter يأخذان الصف الظاهر عليه الشريط؛ النقر يأخذ الصف المنقور.
- للمطوّر: الواجهة تُبنى الآن (`web/`، `npm run build`، بدون تثبيت؛ تستعمل vite الموجود في `F:/Server RedM/Wraith Core/node_modules`)، والناتج في `web/build`. صفحة تجربة: `npm run dev` ثم `dev.html?lang=ar&open=1`.
- تجربة اللعبة المطلوبة: افتح الشات (T) واكتب / وتحرك في القائمة بالأسهم والماوس ثم Tab؛ أرسل /me و /do؛ تأكد أن رسالة خطأ (أمر بلا صلاحية) عليها شريط أحمر، وأن لاعب VIP يظهر بلون رتبته واسمه الملوّن؛ جرّب العربي والإنجليزي، ودقة 720p وشاشة عريضة.

## 1.1.11 — 2026-11-06

- تجربة اللعبة المطلوبة: اكتب /me يمسك الحبل وتأكد أنه فوق رأسك وليس في الشات؛ اكتب / بحساب لاعب ثم بحساب إداري وقارن القائمة؛ اكتب /far ثم Tab.
